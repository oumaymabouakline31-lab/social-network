# Frontend

This is the frontend for the Social Network project, built with Next.js and React.

## Overview

- Framework: `Next.js 16`
- UI: `React 19` with Tailwind CSS 4
- Client-side auth state is managed in `context/AuthContext.tsx`
- API calls use `lib/api.ts` and target the backend at `NEXT_PUBLIC_API_URL`
- The main app structure is under `app/`

## Getting Started

1. Open a terminal in `frontend`
2. Install dependencies:

```bash
npm install
```

3. Create or update `.env.local` if you need a custom backend URL:

```env
NEXT_PUBLIC_API_URL=http://localhost:8080
```

4. Run the development server:

```bash
npm run dev
```

5. Open the app in your browser:

```text
http://localhost:3000
```

## Important Files

- `app/layout.tsx` – root layout and `AuthProvider`
- `app/page.tsx` – main homepage component
- `context/AuthContext.tsx` – authentication context and login flow
- `lib/api.ts` – shared API helper with `credentials: include`
- `package.json` – scripts and dependencies

## Useful Scripts

- `npm run dev` - start the frontend in development mode
- `npm run build` - build the production app
- `npm run start` - start the built app
- `npm run lint` - run ESLint

## Notes

- The frontend expects a backend API running separately, typically at `http://localhost:8080`.
- `NEXT_PUBLIC_API_URL` is used by `lib/api.ts` to build backend requests.

## Files and folders that are not essential for source control

These are generated or local files and do not need to be committed:

- `.next/` - Next.js build output
- `node_modules/` - installed dependencies
- `.env.local` - local environment overrides

`next-env.d.ts` is generated by Next.js and can be recreated automatically if needed.

`next.config.ts` is currently empty and only required if you add custom Next.js configuration.
